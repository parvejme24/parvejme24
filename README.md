### 🧑‍💻 About Me

## About Me

I'm **Md Parvej**, a full-stack developer from Dhaka, Bangladesh 🇧🇩 — building scalable web applications, SaaS products, and AI-powered automation workflows.

By day I write code; by night I study physics — so I approach software the way physicists approach problems: **break it down, find the pattern, build the simplest system that works.**

I specialize in **React/Next.js ecosystems, API-driven backends, and workflow automation** with n8n, Make.com, and Apify — turning repetitive business processes into automated systems that run while you sleep.

Currently expanding into **DevOps** (Docker, CI/CD, AWS) to ship production-ready infrastructure, not just code.

> I believe great products come from solving real problems, not stacking technologies.
